Building a Dynamic Blog Section

Published on July 28, 2025

I made my blog load posts dynamically from a JSON file using JavaScript. This makes it easier to manage and update content without editing the HTML directly.

For Part Two, I created a posts.json file to store my blog entries and used JavaScript's fetch() API to load them dynamically. When the blog page loads, JavaScript fetches the JSON, creates DOM elements for each post, and inserts them into the page. This way, I can add or edit blog posts by just updating the JSON file. I styled the blog posts to match the rest of the portfolio layout.
